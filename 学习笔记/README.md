## 用法

**每次开始前**（约 2 分钟，比看视频划算）：

```powershell
# 1. 确认项目没坏（计划第 230 行的规矩）
uvicorn main:app --reload
# 打开 http://127.0.0.1:8000/api/homepage
# 注意：别用 /docs 验证 —— Swagger 的 JS/CSS 走 jsdelivr，会 ERR_CONNECTION_RESET

# 2. 看上次停在哪
Get-Content 学习笔记\下一步计划.md

# 3. 确认工作区状态
git status --short --untracked-files=all
git log --oneline
```

**每次结束后**：

1. 在 `工作日志.md` 追加一条（日期 + 做了什么 + 卡在哪）
2. 更新 `进度.md` 的状态
3. 把下次要做的写进 `下一步计划.md`
4. `git add` + `commit`（哪怕只有一行改动 —— 暑假纪律那条）

## 约定

- 笔记文件**进 git**：它们和代码一起变化，追踪「当时为什么这么改」很有价值
- 不写密钥、token、密码。**`.env` 永远不进 git**（已用 `git check-ignore -v .env` 验证过生效）
- 时间格式统一 `YYYY-MM-DD`
