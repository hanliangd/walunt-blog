# xinghuisama.top 音乐卡片 / 音乐模块 逆向分析

> 分析时间：2026-10-14
> 目标站点：https://www.xinghuisama.top/
> 技术栈：Next.js 15 (App Router) + React 19 + Tailwind CSS 4 + framer-motion + Turbopack 构建
> 部署：Vercel（响应头 `Server: Vercel`）

---

## 一、结论先说：**接入了服务端 API，不是本地循环**

| 问题 | 结论 |
| --- | --- |
| 是否接 API | ✅ 是。前端请求同域服务端路由 `GET /api/music?ids=<逗号分隔歌曲ID>` |
| 是否本地循环 | ❌ 不是。站点没有任何本地音频资源，`public/` 下也没有 mp3（只有 `siamese-cat.png` 等图片） |
| 音源来自哪里 | 接口返回的是**网易云音乐**外链：`https://music.163.com/song/media/outer/url?id=<id>.mp3`（302 跳转到 `m7xx.music.126.net` CDN） |
| 播放器实现 | 原生 `<audio>` 元素 + React Context（`MusicProvider` / `useMusic`），**不是** APlayer / Meting |
| 播放模式 | `loop`（列表循环）/ `single`（单曲循环）/ `random`（随机） |
| 歌词 | 接口直接返回 LRC 文本字符串，前端用正则解析成 `{time, text}[]` |
| 缓存 | 无 localStorage / sessionStorage 缓存，进页面重新拉取 |

## 二、模块构成（3 个 UI + 1 个 Provider）

```
MusicProvider  (React Context，内部持有一个 <audio>)
├── MusicCard        首页网格里的"音乐卡片"（点击跳 /music）
├── MusicMiniPlayer  右下角可拖拽悬浮迷你播放器（首页隐藏）
└── /music 页面       "云端乐律" 完整播放器 + 歌词 / 歌单
```

- Provider 与三个 UI 都打进 Turbopack 的共享 chunk（`0ph0hub54gnw..js`、`0-3vain8_gk3-.js`、`04~8.xb3ygh9w.js`），文件名是哈希，会随构建变化。
- `/music` 页面是**纯客户端渲染**：SSR 只有骨架，`isLoading=true` 时显示 `CONNECTING...`。
- 首页 HTML 里能找到 1 处 `CONNECTING`（卡片加载态），`/music` 页面 HTML 里 0 处（完全靠 JS 渲染）。

## 四、接口协议：`GET /api/music?ids=`

### 实测

```bash
# 正常
curl "https://www.xinghuisama.top/api/music?ids=1809646618,3361076230"
# 200  application/json   Server: Vercel
# Cache-Control: public, max-age=0, must-revalidate

# 不带 ids
curl "https://www.xinghuisama.top/api/music"        # 400

# 不存在的 id
curl "https://www.xinghuisama.top/api/music?ids=99999999"
# 200  [{"id":"99999999","error":"not_found"}]
```

### 响应体（每个 id 一项）

```json
[
  {
    "id": "1809646618",
    "name": "云月谣",
    "artist": "兰音Reine",
    "author": "兰音Reine",
    "cover": "https://p1.music.126.net/-9rfjKZrdHFNXzFDzw8u7A==/109951165603980116.jpg",
    "pic":   "https://p1.music.126.net/-9rfjKZrdHFNXzFDzw8u7A==/109951165603980116.jpg",
    "url":   "https://music.163.com/song/media/outer/url?id=1809646618.mp3",
    "lrc":   "[00:00.00] 作词 : 聂蓉绝恋\n[00:00.13] 作曲 : 兰音Reine\n..."
  }
]
```

要点：
- `name / artist / author / cover / pic` 是**冗余字段**（前端做了 `||` 兜底），说明作者预留了多数据源。
- `url` 是网易云 `outer/url` 外链，服务端**不代理音频流**，只代理元数据（为了绕 CORS）。
- `lrc` 直接给完整 LRC 文本；前端也支持 `lrcUrl` 字段（另一个 URL 拉歌词），但接口没用上。
- `quality` 等额外参数被忽略。

### 真实音源验证

```bash
curl -I -A "Mozilla/5.0" "https://music.163.com/song/media/outer/url?id=1809646618.mp3"
# HTTP/1.1 302 Found            Server: volc-dcdn
# Location: http://m701.music.126.net/20261014120614/.../xxx.mp3?vuutv=...
```

即 `music.163.com/song/media/outer/url` 是网易云的**公开外链接口**，302 到 CDN。
服务端路由大概率就是：
1. 调网易云 `GET /api/song/detail?ids=[...]` 拿歌名 / 歌手 / 封面；
2. 调 `GET /api/song/lyric?id=...&lv=-1&kv=-1&tv=-1` 拿 LRC；
3. 拼出 `outer/url` 作为播放地址。

### 上游网易云接口实测复现（httpx 0.28.1 / 2026-10-14）

为了确认"服务端到底调的哪个接口"，我在**本地用 httpx 直连网易云**逐一复现（仅带
`User-Agent` + `Referer: https://music.163.com/`，无 Cookie、无登录）：

| 上游请求 | 实测结果 | 可用性 |
| --- | --- | --- |
| `GET /api/song/detail?ids=[1809646618]` | 200，`songs[0]` → `name=云月谣`、`artists[0].name=兰音Reine`、`album.picUrl=...5639395138885805.jpg` | ✅ |
| `GET /api/v3/song/detail?c=[{"id":1809646618}]` | 200，`name=云月谣`、`ar[0].name=兰音Reine`、`al.picUrl=...109951165603980116.jpg` | ✅（字段名不同，`ar/al`） |
| `GET /api/song/lyric?id=1809646618&lv=-1&kv=-1&tv=-1` | 200，`code=200`，`lrc.lyric` 776 字符，首行 `[00:00.00] 作词 : 聂蓉绝恋` | ✅ |
| `HEAD /song/media/outer/url?id=1809646618.mp3` | 302 → `m701.music.126.net/.../<hash>.mp3?vuutv=...` | ✅ 可播 |
| `GET`（跟随跳转）可播歌曲 | 最终 **200 `content-type: audio/mpeg`**，约 2.5 MB | ✅ |
| `GET`（跟随跳转）不存在/不可播歌曲（如 `999999999999`） | 302 → **`https://music.163.com/404`**，最终 200 但 `content-type: text/html`、10 万字节 HTML | ❌ `<audio>` 直接报错 |

**结论（可直接用作判定规则）**：
- 元数据接口 `song/detail`（v1 或 v3）+ `song/lyric` 都**无需登录**即可调用，所以自建代理完全可行。
- 判断一首歌能不能放，最稳的不是看 `fee`，而是看 `outer/url` 的 302 **`Location` 主机名**：
  含 `music.126.net` = 真音源；跳回 `music.163.com/404` = 不可播。
- 注意：用 `curl` 测时 URL 里的 `[]` 会被当成 glob，需要加 `-g/--globoff`，否则会**返回空**让人误判接口失效（本次就踩过一次）。

### 5.1 `MusicProvider`（Context + 原生 audio）

```tsx
type Song = {
  id: string; title: string; artist: string; cover: string;
  src: string;                 // 播放地址
  lrcUrl: string | null;
  lyrics: { time: number; text: string }[];
};

const MusicCtx = createContext<MusicContextValue | null>(null);

export function MusicProvider({ children }: { children: ReactNode }) {
  const [playlist, setPlaylist]         = useState<Song[]>([]);
  const [currentIndex, setCurrentIndex] = useState(0);
  const [isPlaying, setIsPlaying]       = useState(false);
  const [progress, setProgress]         = useState(0);      // 0~100
  const [currentTime, setCurrentTime]   = useState(0);
  const [duration, setDuration]         = useState(0);
  const [currentLyric, setCurrentLyric] = useState("正在连接高可用神经云端...");
  const [isLoading, setIsLoading]       = useState(true);
  const [volume, setVolume]             = useState(1);
  const [isMuted, setIsMuted]           = useState(false);
  const [playMode, setPlayMode]         = useState<"loop" | "single" | "random">("loop");
  const [lyrics, setLyrics]             = useState<{ time: number; text: string }[]>([]);
  const audioRef = useRef<HTMLAudioElement>(null);

  // ① 进入站点就拉歌单（全站只拉一次，Provider 挂在根 layout）
  useEffect(() => {
    let alive = true;
    const load = async () => {
      try {
        const res  = await fetch(`/api/music?ids=${siteConfig.cloudMusicIds.join(",")}`);
        const data = await res.json();
        const list: Song[] = data
          .filter((s: any) => s && s.url && !s.error)          // 过滤失败项
          .map((s: any) => ({
            id:     s.id || Math.random().toString(),
            title:  s.name  || "未知歌曲",
            artist: s.artist || s.author || "未知歌手",
            cover:  s.cover || s.pic || "https://bu.dusays.com/2026/03/24/69c24230a5ff8.jpg",
            src:    s.url,
            lrcUrl: null,
            lyrics: s.lrc ? parseLrc(s.lrc) : [],
          }));
        if (!alive) return;
        if (list.length > 0) setPlaylist(list);
        else setCurrentLyric("云端链路受阻");
        setIsLoading(false);
      } catch {
        if (alive) { setCurrentLyric("网络初始化失败"); setIsLoading(false); }
      }
    };
    siteConfig.cloudMusicIds?.length > 0 ? load() : setIsLoading(false);
    return () => { alive = false; };
  }, []);
```


```tsx
  // ② 切歌：重置歌词；若正在播放则续播
  useEffect(() => {
    if (playlist.length === 0) return;
    let alive = true;
    const song = playlist[currentIndex];
    setLyrics([]);
    setCurrentLyric("♪ 正在缓冲 ♪");
    if (song.lyrics?.length > 0) {
      setLyrics(song.lyrics);
      setCurrentLyric(song.lyrics[0]?.text || "♪ 纯享音乐 ♪");
    } else if (song.lrcUrl) {
      fetch(song.lrcUrl).then(r => r.text()).then(text => {
        if (!alive) return;
        const parsed = parseLrc(text);
        setLyrics(parsed);
        setPlaylist(prev => {   // 回写缓存，避免重复请求
          const next = [...prev]; next[currentIndex].lyrics = parsed; return next;
        });
      }).catch(() => alive && setCurrentLyric("♪ 纯享音乐 ♪"));
    }
    if (isPlaying && audioRef.current) audioRef.current.play()?.catch(() => setIsPlaying(false));
    return () => { alive = false; };
  }, [currentIndex, playlist.length]);

  // ③ 音量 / 静音（静音时直接置 volume=0，不暂停）
  useEffect(() => {
    if (audioRef.current) audioRef.current.volume = isMuted ? 0 : volume;
  }, [volume, isMuted]);

  // ④ 上/下一首：random 模式随机，否则取模
  const nextSong = () => {
    if (playMode === "random") setCurrentIndex(Math.floor(Math.random() * playlist.length));
    else setCurrentIndex(i => (i + 1) % playlist.length);
  };
  const prevSong = () => {
    if (playMode === "random") setCurrentIndex(Math.floor(Math.random() * playlist.length));
    else setCurrentIndex(i => (i - 1 + playlist.length) % playlist.length);
  };

  // ⑤ <audio> 的 onTimeUpdate —— 进度条 + 歌词滚动全靠它
  const handleTimeUpdate = () => {
    if (!audioRef.current) return;
    const { currentTime: t, duration: d } = audioRef.current;
    setCurrentTime(t);
    setDuration(d || 0);
    setProgress((t / (d || 1)) * 100);
    if (lyrics.length > 0) {
      const hit = lyrics.slice().reverse().find(l => t >= l.time);  // 反向找最近一句
      if (hit && hit.text !== currentLyric) setCurrentLyric(hit.text);
    }
  };

  const currentSong = playlist[currentIndex];

  return (
    <MusicCtx.Provider value={{
      playlist, currentIndex, currentSong, isPlaying, progress, currentTime, duration,
      currentLyric, isLoading, volume, isMuted, playMode,
      togglePlay: () => {
        if (!audioRef.current) return;
        isPlaying ? audioRef.current.pause()
                  : audioRef.current.play().catch(() => setIsPlaying(false));
        setIsPlaying(!isPlaying);
      },
      nextSong, prevSong,
      handleSeek: (e) => {
        const p = Number(e.target.value);
        setProgress(p);
        if (audioRef.current?.duration)
          audioRef.current.currentTime = (p / 100) * audioRef.current.duration;
      },
      playSong: (i) => { setCurrentIndex(i); if (!isPlaying) setIsPlaying(true); },
      setVolume: (v) => { setVolume(v); if (isMuted && v > 0) setIsMuted(false); },
      toggleMute: () => setIsMuted(!isMuted),
      togglePlayMode: () =>
        setPlayMode(m => m === "loop" ? "single" : m === "single" ? "random" : "loop"),
    }}>
      {children}
      {/* 全站唯一的音频实例，真正的"播放器内核" */}
      {currentSong && (
        <audio
          ref={audioRef}
          src={currentSong.src}
          onTimeUpdate={handleTimeUpdate}
          onLoadedMetadata={handleTimeUpdate}
          onEnded={() => {
            if (playMode === "single" && audioRef.current) {
              audioRef.current.currentTime = 0;        // 单曲循环
              audioRef.current.play();
            } else nextSong();
          }}
        />
      )}
    </MusicCtx.Provider>
  );
}

export function useMusic() {
  const ctx = useContext(MusicCtx);
  if (!ctx) throw new Error("useMusic must be used within MusicProvider");
  return ctx;
}
```


### 5.2 LRC 解析（正则）

```ts
function parseLrc(lrc: string) {
  const lines = lrc.split("\n");
  const out: { time: number; text: string }[] = [];
  // 支持 [mm:ss]、[mm:ss.xx]、[mm:ss:xx]
  const re = /\[(\d{2,}):(\d{2})(?:[.:](\d{2,3}))?\]/g;
  let matched = false;
  for (const line of lines) {
    const text = line.replace(/\[\d{2,}:\d{2}(?:[.:]\d{2,3})?\]/g, "").trim();
    if (!text) continue;
    let m: RegExpExecArray | null;
    while ((m = re.exec(line)) !== null) {
      matched = true;
      const mm = parseInt(m[1], 10);
      const ss = parseInt(m[2], 10);
      const ms = m[3] ? parseFloat(`0.${m[3]}`) : 0;
      out.push({ time: mm * 60 + ss + ms, text });
    }
  }
  // 无时间戳（纯文本歌词）→ time = -1
  return matched
    ? out.sort((a, b) => a.time - b.time)
    : lines.map(l => ({ time: -1, text: l.trim() })).filter(l => l.text);
}
```

### 5.5 `/music` 页面「云端乐律」

- 标题「云端乐律」/ 副标题「在代码的缝隙中寻找灵魂的共鸣」；
- 布局：`flex flex-col md:grid md:grid-cols-12`，高 `md:h-[calc(100vh-320px)] md:min-h-[600px] md:max-h-[720px]`；
- 左 5 列：`w-40/48/64` 旋转封面 + 外层 `blur-[35px]` 光晕 + `border-[4px]/[6px]` 唱片圈，`isPlaying` 时放大加亮；
- 右 7 列：歌词 / 歌单两个 tab（`useState<"lyrics"|...>("lyrics")`）;
- 控制条用 **lucide-react** 图标：`skip-back`、`skip-forward`、`repeat`、`shuffle`、`disc-3`、`volume-2`、`volume-x`；
- Provider 的 `selectSong / playSong` 用于歌单点播，`playMode` 三态切换；
- 歌词高亮用 `useMemo` 算出当前行 index，随 `currentTime` 滚动。

```ts
  "User-Agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 Chrome/120 Safari/537.36",
  Referer: "https://music.163.com/",
  Cookie: "appver=2.0.2",          // 部分接口需要
};

export async function GET(req: Request) {
  const ids = new URL(req.url).searchParams.get("ids");
  if (!ids) return Response.json({ error: "missing ids" }, { status: 400 });

  const list = await Promise.all(
    ids.split(",").map(async (id) => {
      try {
        const [detailRes, lyricRes] = await Promise.all([
          fetch(`https://music.163.com/api/song/detail?ids=[${id}]`, { headers: NET_EASE_HEADERS }),
          fetch(`https://music.163.com/api/song/lyric?id=${id}&lv=-1&kv=-1&tv=-1`,
                { headers: NET_EASE_HEADERS }),
        ]);
        if (!detailRes.ok) return { id, error: "not_found" };

        const song = (await detailRes.json())?.songs?.[0];
        if (!song) return { id, error: "not_found" };
        const lrc = (await lyricRes.json())?.lrc?.lyric ?? "";

        return {
          id,
          name:   song.name,
          artist: song.artists?.map((a: any) => a.name).join("/"),
          author: song.artists?.[0]?.name,
          cover:  song.album?.picUrl,
          pic:    song.album?.picUrl,
          url:    `https://music.163.com/song/media/outer/url?id=${id}.mp3`,
          lrc,
        };
      } catch {
        return { id, error: "network_error" };
      }
    })
  );
  return Response.json(list);
}
```

```python
# music.py —— 本文件已在本地用 httpx 0.28.1 实测跑通（含 not_found / unplayable 分支）
import asyncio
import json
import time

import httpx
from fastapi import APIRouter, HTTPException, Query

router = APIRouter(prefix="/api", tags=["music"])

HEADERS = {
    "User-Agent": ("Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 "
                   "(KHTML, like Gecko) Chrome/120.0.0.0 Safari/537.36"),
    "Referer": "https://music.163.com/",
}
OUTER = "https://music.163.com/song/media/outer/url?id={sid}.mp3"

_CACHE: dict[str, tuple[float, dict]] = {}   # 进程内缓存，避免高频回源被限流
TTL = 600                                     # 秒


async def _detail(client: httpx.AsyncClient, sid: str) -> dict | None:
    """取元数据：v3 接口优先（字段 ar/al），失败回退 v1（字段 artists/album）"""
    try:
        r = await client.get("https://music.163.com/api/v3/song/detail",
                             params={"c": json.dumps([{"id": int(sid)}])},
                             headers=HEADERS)
        s = (r.json().get("songs") or [None])[0]
        if s:
            return {
                "name": s.get("name"),
                "artist": [a.get("name", "") for a in s.get("ar", [])],
                "pic": (s.get("al") or {}).get("picUrl"),
            }
    except (ValueError, httpx.HTTPError):
        return None                            # sid 不是数字 → 直接判不存在

    r = await client.get("https://music.163.com/api/song/detail",
                         params={"ids": f"[{sid}]"}, headers=HEADERS)
    s = (r.json().get("songs") or [None])[0]
    if not s:
        return None
    return {
        "name": s.get("name"),
        "artist": [a.get("name", "") for a in s.get("artists", [])],
        "pic": (s.get("album") or {}).get("picUrl"),
    }


async def _probe(client: httpx.AsyncClient, sid: str) -> bool:
    """判断 outer/url 是否指向真音源：302 到 music.126.net 才算可播"""
    try:
        r = await client.head(OUTER.format(sid=sid), headers=HEADERS, follow_redirects=False)
        return r.status_code in (301, 302) and "music.126.net" in r.headers.get("location", "")
    except httpx.HTTPError:
        return False


async def _one(client: httpx.AsyncClient, sid: str) -> dict:
    detail = await _detail(client, sid)
    if not detail:
        return {"id": sid, "error": "not_found"}
    if not await _probe(client, sid):
        return {"id": sid, "error": "unplayable"}   # VIP / 下架 / 无版权
    lyric = await client.get("https://music.163.com/api/song/lyric",
                             params={"id": sid, "lv": -1, "kv": -1, "tv": -1},
                             headers=HEADERS)
    return {
        "id": sid,
        "name": detail["name"],
        "artist": "/".join(detail["artist"]),       # 与前端 "artist" 字段对齐
        "author": detail["artist"][0] if detail["artist"] else None,
        "cover": detail["pic"],
        "pic": detail["pic"],
        "url": OUTER.format(sid=sid),
        "lrc": (lyric.json().get("lrc") or {}).get("lyric", ""),
    }


@router.get("/music")
async def music(ids: str = Query(..., description="逗号分隔的网易云歌曲 ID")):
    id_list = [i.strip() for i in ids.split(",") if i.strip()]
    if not id_list:
        raise HTTPException(status_code=400, detail="missing ids")   # 与原站行为一致

    now, result, todo = time.time(), [None] * len(id_list), []
    for idx, sid in enumerate(id_list):
        hit = _CACHE.get(sid)
        if hit and now - hit[0] < TTL:
            result[idx] = hit[1]
        else:
            todo.append((idx, sid))

    if todo:
        async with httpx.AsyncClient(timeout=15) as client:
            items = await asyncio.gather(*(_one(client, sid) for _, sid in todo))
        for (idx, sid), item in zip(todo, items):
            _CACHE[sid] = (now, item)
            result[idx] = item

    return result
```

## 七、局限与坑（原站同样存在）

1. **`outer/url` 不是万能的**
   它只对**真正可播**的歌曲 302 到 `m*.music.126.net` 真音源；VIP / 下架 / 无版权歌曲
   会被 302 到 `https://music.163.com/404`（最终 200 但 `content-type: text/html`），
   浏览器 `<audio>` 直接报错。实测例：`186016`（晴天）`fee=0` 却属于这一类，
   所以只能靠探测 `Location` 判定，不能靠 `fee` 字段。原站对此**没有 fallback**，只是把该条 `filter` 掉。
2. **没有本地兜底**
   `cloudMusicIds` 全挂时，卡片只显示「No Music Available / 请检查播放列表或网络连接」，
   不会降级到本地音源（所以答案很明确：不是本地循环）。
3. **首屏无内容**
   `/music` 完全依赖客户端 fetch，SEO 拿不到歌单，除骨架屏外无占位。
4. **歌曲 ID 明文暴露**
   `cloudMusicIds` 直接躺在客户端 bundle 里，任何人可读可改。
5. **无鉴权、无缓存头**
   `/api/music` 是公开接口，`Cache-Control: public, max-age=0, must-revalidate`，
   等于每次请求都回源网易云；量大了会被限流。建议自己加 5~30 分钟
   内存 / Redis 缓存 + IP 频控。
6. **CORS**
   浏览器不能直接请求 `music.163.com` 的 API，必须像原站一样**由服务端代理**元数据；
   但音频 `<audio src>` 直连不受同源策略约束，所以音频流可以不过服务端。
7. **版权提醒**
   仅供个人学习 / 自建站使用；公开展示第三方音源存在合规风险。

## 八、一句话总结

> 它的音乐模块 = **一份写死的网易云歌曲 ID 列表** + **一个自建的 `/api/music` 服务端代理**
> （转发网易云 `song/detail` + `lyric`，拼出 `outer/url` 外链） +
> **一个挂在根部 layout 的 React Context 播放器**（单个 `<audio>` + LRC 正则解析 + 三种播放模式）。
> 首页用一张「旋转封面 + 打字机歌词」的玻璃拟态卡片引流，`/music` 页是完整播放器，
> 右下角还有可拖拽迷你播放条。
> **不是本地循环，是实实在在走 API 的在线播放。**
