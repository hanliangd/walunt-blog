## 和原版的差异（为什么改）

| 原计划 | 改成 | 为什么 |
|---|---|---|
| D1 用 AI 生成 HTML+CSS | **手写 HTML + 复用现有 CSS** | 你有 60 KB 现成样式 + `布局地图.md`；AI 生成的 CSS 无法验证对错（Cline 那次已经吃过亏） |
| D2 发 5-10 篇 | **3 篇**，语料补 `学习笔记/*.md` | `posts` 现在 **0 篇**，Day 3 会卡在这；笔记是更好的语料 |
| D3 装 `sentence-transformers` | **chromadb 自带 embedding** | 省 2.5 GB 的 PyTorch；且 chromadb 可能改 FastAPI/pydantic 版本，装前先 `pip freeze` |
| D3 直接写索引脚本 | **上午先跑 hello world 验证环境** | 依赖冲突/模型下载是这类活最常见的卡点 |
| D4 直接改 chat_stream | **先 commit + 备份** | 改的是刚跑通的核心 |
| D5 才做安全测试 | **注入并入 D5 上午** + D5 当缓冲日 | 注入只是 4 次聊天 + 一段演示（40-60 分钟），不是半天 |
| 每天早中晚 8-10h | **每天 4-5h，晚上不排硬活** | 那是你平时 5-7 倍量，撑不住 |
