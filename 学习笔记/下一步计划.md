## 🔵 第 4 件：给 CSS 补响应式（2-3 小时，**不要看视频**）

**动机**：跟着黑马学了媒体查询和响应式，但复现不出来。**根源是从来没在项目里写过一次**（`index修改版.css` 573 行里 `@media` 数量 = **0**，硬编码 px = **122**）。

**方法（练手材料就是自己的代码，不要新建项目）**：

1. 打开浏览器 **F12 → 设备模拟**，宽度拖到 **375px**
   → 你会看到横向滚动条或布局挤爆。**先看到问题**
2. 加**第一个**断点，只改一件事：
   ```css
   @media (max-width: 768px) {
     /* 只做一件事：把多列网格改成单列 */
   }
   ```
   （你那 573 行里有 2 处 `grid-template`，改成 `1fr` 就行）
3. 刷新，再拖宽度，**看变化**
4. 重复 2-3 次，**每次只解决一个具体问题**（字体太大 / 图片溢出 / 导航挤在一起）
5. 把明显的 `px` 换成 `clamp()`：
   ```css
   font-size: clamp(1.5rem, 4vw, 3rem);   /* 最小 1.5rem，最大 3rem，中间跟视口走 */
   ```

**做完是「做过」，不是「看过」。** 而且完全没引入新工具。
