## 三、主线（不许同时开两条以上）

### 🚑 A0 · 线上止血 —— **最先做，20 分钟**

> **顺序理由**：线 A 是"让别人看得懂"，A0 是"不让别人搞你"。**顺序反了。**
> 而且 ③ 和备案直接相关：**备案审核期间网站上能看到「注册」入口，会被质疑"这是不是交互性网站"** ✗
> 个人备案只允许非经营性个人网站 —— AI 对话本身问题不大（无 UGC 发布），但**开放注册是实打实的减分项** ✓

| # | 修什么 | 怎么修 | 验收判据 |
|---|---|---|---|
| A0-1 | `context_text` | `main.py:358` 的 `if hits:` **之前**加 `context_text = ""` | 问一个笔记里没有的问题（如"今天天气"）→ **不 500** |
| A0-2 | `/notes` 收窄 | 删 `app.mount("/notes",...)`，换成**路由 + 白名单**（只放 4 个笔记）| `curl /notes/部署手册*.md` → **404** ✓ |
| A0-3 | 关注册 | 路由改成 `status_code=404` 直接抛，**或**加邀请码 | `curl -X POST /api/register` → **404/403** ✓ |
| A0-4 | 关文档 | `app = FastAPI(docs_url=None, redoc_url=None, openapi_url=None)` | `curl /docs` 和 `/openapi.json` → **404** ✓ |
| A0-5 | 详情查 status | 改成 `select(Post).where(Post.id == id, Post.status == "published")` | 用一个**草稿**的 id 访问 → **404** ✓ |
| A0-6 | 删 `/chat` | 确认 `chat-api.js` 只用 `/api/chat/stream` 后整块删 | `curl -X POST /chat` → **404/405** ✓ |

**代码参考（A0-2 白名单）**：

```python
NOTE_PUBLIC = {"踩坑记录", "工作日志", "进度", "反思-业务逻辑分层"}

@app.get("/notes/{name}.md")
def get_note_md(name: str):
    if name not in NOTE_PUBLIC:          # ← 白名单：部署手册/速查 自动 404
        raise HTTPException(404, "笔记不存在")
    p = NOTES_DIR / f"{name}.md"
    if not p.is_file():
        raise HTTPException(404, "笔记不存在")
    return FileResponse(p, media_type="text/markdown; charset=utf-8")
```

> 改完 `systemctl restart walunt` + `sleep 8` + 逐条 `curl` 验收 ✓

## 四、六周一个周期（节奏比意志力可靠）

```
第 1 周   选 1 件事 → 把"验收判据"抄下来，写清楚"做到什么算完"
第 2-4 周 做。每周固定 2-3 次，每次 2-3 小时
第 5 周   验收：对着判据打勾。不能全打 → 只补这一件
第 6 周   写进工作日志 + 复盘"卡在哪" → 再开下一件
```

**四条铁律**：

1. **一次只推一件主线** ✓（B1 没做完不碰 B2）
2. **每件事必须先写验收判据** ✓（"做完了"必须是**判据**，不是形容词）
3. **超时 1.5 倍就停手** ✓（10h 的活干到 15h 还没完 → 停下来记"卡在哪" → 下周再来）
4. **每次结束必须留在一个"能跑"的状态** ✓
